ISTRUZIONI RAPIDE PER CREARE IL FILE .EXE SU WINDOWS
=====================================================

1. Estrai tutti i file di questo archivio ZIP in una cartella sul tuo PC Windows.
2. Assicurati di avere Python installato (se non lo hai, scaricalo da python.org spuntando "Add Python to PATH" durante l'installazione).
3. Fai doppio clic sul file "crea_exe.bat".
4. Lo script installera' automaticamente PyQt6, requests e PyInstaller e generera' il programma standalone.
5. Al termine, troverai il file eseguibile "IPTV_EPG_TMDB_Studio.exe" dentro la sottocartella "dist".
